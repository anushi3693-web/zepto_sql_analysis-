# Zepto Inventory & Sales Analytics - SQL Project

Analyzed 3000+ products from Zepto dataset using PostgreSQL & pgAdmin to uncover revenue, discount, and inventory insights.

## Tools Used
- PostgreSQL, pgAdmin, SQL

## Key Business Questions Solved (8 Queries)
1. Out of Stock vs In-Stock product count
2. Category-wise Estimated Revenue (price * quantity)
3. High MRP (>500) but Low Discount (<10%) products
4. Top 5 Categories with Highest Average Discount
5. Price Per Gram analysis for products >100g
6. Inventory Segmentation using CASE WHEN (Low/Medium/Bulk)
7. Total Inventory Weight per Category

## SQL Concepts Used
GROUP BY, SUM(), AVG(), CASE WHEN, ROUND(), DISTINCT, Filtering
